# Сайт «Единый оператор ЮС»

Готовый статический прототип на HTML, CSS и JavaScript. Без npm, сборщиков и прочего ритуального шаманства.

## Быстрый запуск

### Самый простой способ
Откройте `index.html` двойным щелчком.

### Нормальный способ через локальный сервер
Откройте терминал в папке сайта и выполните:

```powershell
py -m http.server 8000
```

Затем откройте в браузере:

```text
http://localhost:8000
```

На Windows можно просто запустить `start_site.bat`.

### Через Visual Studio Code
1. Откройте папку сайта.
2. Установите расширение **Live Server**.
3. Нажмите правой кнопкой по `index.html`.
4. Выберите **Open with Live Server**.

## Страницы
- `index.html` — главная
- `about.html` — о компании
- `passengers.html` — пассажирам
- `carriers.html` — кабинет перевозчика
- `cards.html` — транспортные карты
- `appeals.html` — обращения
- `contacts.html` — контакты

## Что работает
- адаптивное меню;
- все переходы между страницами;
- демонстрационный поиск маршрута;
- создание обращения;
- генерация номера;
- хранение обращения в localStorage;
- проверка статуса в том же браузере;
- ссылки на телефон и Go2bus.

## Что пока демонстрационное
- показатели кабинета перевозчика;
- новости об изменениях;
- настоящий поиск расписаний;
- отправка обращений организации;
- авторизация;
- интеграция с АСУОП и транспортными API.

Для боевого сайта понадобятся backend, база данных, админ-панель, политика обработки персональных данных и реальные интеграции.
